# 📚 Jogo da Memória Literário
 
## Levantamento de Requisitos
 
### Requisitos Funcionais
- O jogo deve permitir virar cartas ao clicar nelas.  
- O sistema deve verificar se duas cartas formam um par.  
- O jogo deve contar e exibir o número de movimentos.  
- O jogo deve contar e exibir o número de pares encontrados.  
- O sistema deve registrar e exibir o tempo de jogo em segundos.  
- O usuário deve poder escolher a dificuldade (4, 6 ou 8 pares).  
- O sistema deve permitir dois modos de jogo: um jogador local e multijogador local.  
- O jogo deve mostrar o jogador atual.  
- Ao encontrar todos os pares, o sistema deve exibir mensagem de fim de jogo.  
- O usuário deve poder reiniciar a qualquer momento.  
- O jogo deve iniciar automaticamente ao carregar a página.  
- As imagens das cartas devem estar relacionadas ao universo literário.  
 
### Requisitos Não Funcionais
- O jogo deve ser desenvolvido em **HTML, CSS e JavaScript puro**.  
- A interface deve ser **responsiva** e intuitiva.  
- O código deve estar **organizado, comentado e seguindo boas práticas**.  
- O design deve ter **tema literário** (cores, imagens e estilo).  
- O jogo deve ser compatível com os navegadores modernos.  
- O desempenho deve ser rápido, sem travamentos.  
- A solução deve permitir publicação online (**GitHub Pages**).  
- O jogo deve promover **concentração e memória** de forma lúdica.  
- O sistema deve suportar partidas de até **2 jogadores alternando turnos**.  
 
---
 
## Tecnologias Utilizadas
- HTML5  
- CSS3  
- JavaScript  
 
## Como Jogar
1. Escolha a dificuldade e o modo de jogo.  
2. Clique nas cartas para revelar os pares.  
3. Encontre todos os pares para vencer.  
4. No modo multiplayer, os jogadores se alternam automaticamente.
